# GEMINI.md: Project Context

## Directory Overview

This directory contains a research project focused on the **Unified Learning Stack (ULS)**, a cognitive architecture for human and machine learning. The project's primary goal is to address critical feedback from peer reviews of the ULS White Paper (v0.4) by providing empirical validation and methodological expansion.

The research is a "non-code" project, with the main artifacts being research reports, data, and analysis scripts rather than a software application. The project follows a structured academic approach, moving from critique and problem definition to simulation, data analysis, and reporting.

## Key Files

This directory is organized around the outputs of a simulated research study. The key files are:

*   **`EXECUTIVE_SUMMARY.md`**: The best place to start. This file provides a high-level overview of the entire research project, including the key findings, a summary of the deliverables, and an honest assessment of the research quality.

*   **`Instructional Prompt ULS.md`**: This file outlines the original research assignment. It details the tasks required to address the gaps in the ULS White Paper, including the need to generate new data and create a functional specification.

*   **`Peer-Review_1.md`** and **`Peer_Review_2.md`**: These files contain the academic peer reviews of the original ULS White Paper. They provide the critical context for the research project, highlighting the key weaknesses that the project aims to address (e.g., lack of empirical evidence, over-stated claims).

*   **`uls_pilot_simulation.py`**: A Python script that generates a simulated dataset for a pilot study of the ULS. The simulation is based on effect sizes from existing cognitive science literature. This script is the core of the project's "empirical" component.

*   **`uls_pilot_data.csv`**: The raw, simulated data generated by the `uls_pilot_simulation.py` script. It contains data for 120 participants across four conditions.

*   **`uls_pilot_statistics.json`**: The statistical analysis of the pilot data, including descriptive statistics, ANOVA results, and pairwise effect sizes (Cohen's d).

*   **`ULS_Critical_Analysis_Report.docx`** and **`ULS_Critical_Analysis_Report.txt`**: The original critical analysis of the ULS White Paper, which likely served as the foundation for the peer reviews. The `.txt` version is a plain text conversion of the `.docx` file.

*   **`docx_to_txt.py`**: A simple Python utility script for converting `.docx` files to `.txt` files.

*   **Other `.md` Reports**: The directory contains several other Markdown files (`ULS_Improvement_Report.md`, `ULS_Research_Expansion_Report.md`, etc.) which are the final, structured reports generated as part of the research project.

## Usage

This directory serves as a self-contained research archive. The intended use is to:

1.  **Understand the ULS Concept:** Start with the `EXECUTIVE_SUMMARY.md` to get a quick overview of the ULS and the research findings.
2.  **Trace the Research Process:** Read the `Peer-Review_*.md` files and the `Instructional Prompt ULS.md` to understand the "why" behind the project.
3.  **Examine the "Empirical" Work:** Review the `uls_pilot_simulation.py` script to understand how the data was generated. Look at `uls_pilot_data.csv` and `uls_pilot_statistics.json` to see the results.
4.  **Read the Final Reports:** The other `.md` files in the directory contain the detailed, structured reports that were the final deliverables of the research project.
