## Phase 3: Research Question Formulation

**Objective:** To formulate a precise, testable research question.

- [ ] Develop a research question focused on a critical gap in the chosen path.
- [ ] Ensure the question is testable and requires new data.

## Phase 4: Experimental Design (Data Generation)

**Objective:** To generate novel research data through a simulated or pilot study.

- [ ] Propose a detailed experimental plan.
- [ ] Define the participant count (N >= 30) or equivalent data analysis.
- [ ] Define the control condition.
- [ ] Execute the simulated or pilot study.
- [ ] Collect and organize the generated data.

## Phase 5: Deliverable Specification

**Objective:** To create a detailed functional specification for the focused component.

- [ ] Write pseudocode for the improved method.
- [ ] Define data structure schemas.
- [ ] Describe the update rules and decision boundaries.
- [ ] Compile the specification into a 50-100 page equivalent document.

## Phase 6: Final Structured Report

**Objective:** To communicate all research findings in a professional academic tone.

- [ ] **Section 1:** Write an explanation of material understanding.
- [ ] **Section 2:** Write a summary of the problem.
- [ ] **Section 3:** Detail the planned steps/phases (methodology).
- [ ] **Section 4:** Propose solutions/improvements based on new data.
- [ ] **Section 5:** Conduct and write a failure analysis.
- [ ] **Section 6:** Describe the final product (data and method).
- [ ] **Section 7:** Suggest future research directions.
- [ ] **Section 8:** Compile a list of referenced materials in APA style.
- [ ] Submit the final report.
